# SQL Week 2 Assignment

## Overview

This repository contains my Week 2 SQL assignment.

The assignment focuses on basic SQL queries using the `sales` database.

## Topics Covered

- SELECT statements
- WHERE filtering
- ORDER BY sorting
- LIMIT
- Retrieving data from different tables

## Assignment Tasks

1. Retrieve payment information from the `payments` table.
2. Find orders with the status **In Process**.
3. Find employees whose job title is **Sales Rep**.
4. Retrieve all information from the `offices` table.
5. Find the five cheapest products.

## File

- `assignment.sql` — Contains all SQL queries for the assignment.

## Database

The queries are designed to work with the `sales` database.
